# customer-retention-analysis

**Project status:** Ongoing

This project explores a Turkish e‑commerce dataset (5,000 orders) to understand what drives high‑value purchases. The main goals are:

- Identify key factors influencing customer spending.
- Build a funnel analysis to see how engagement (pages viewed, session duration) relates to high‑value orders.
- Provide data‑driven recommendations for marketing and product teams.

## Current Progress
- ✅ Data cleaning and feature engineering
- ✅ Exploratory Data Analysis (EDA)
- 🔄 Funnel analysis and statistical testing
- 🔄 Final insights and recommendations

## Tools Used
Python (pandas, matplotlib, seaborn, scipy), Jupyter Notebook.

## How to Run
1. Clone this repository.
2. Install required libraries: `pip install -r requirements.txt` (if available).
3. Open `notebooks/01_eda_funnel_analysis.ipynb` in Jupyter.

## Data
The dataset is in the `data/` folder – it includes 18 features like demographics, product details, and session metrics. See [`data/DATASET_README.md`](data/DATASET_README.md).
